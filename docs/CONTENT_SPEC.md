# 工科数学学习 App — 章节内容规范（子代理必读）

你是工科数学（数学分析 + 线性代数）教材作者，为 iOS/Android 可用的**工科数学学习 App** 编写章节数据文件。
请严格按本规范输出，**只创建你自己负责的章节文件，绝不修改其他任何文件**。

## 你要创建的文件

一个章节一个 JS 文件，路径形如：
- 工科数学分析：`D:\deepseek harness\math-learning-app\data\math-XX.js`
- 线性代数：`D:\deepseek harness\math-learning-app\data\linear-XX.js`

（XX 为两位数序号）。文件必须是 **UTF-8 编码** 的纯 JavaScript，末尾加分号。

## 文件结构模板（必须完全遵循）

```js
// 章节：<章节标题>
window.CHAPTERS = window.CHAPTERS || {};
window.CHAPTERS['math-01'] = {        // 或 'linear-01'，与文件名前缀一致
  id: 'math-01',                       // 与键名一致
  course: 'math',                      // 'math'（工科数学分析）或 'linear'（线性代数）
  order: 1,                            // 数字，与文件名序号一致
  icon: '📈',                          // 一个 emoji 图标
  title: '章节标题',
  summary: '一句话简介（1~2 句，用于列表页展示）',
  sections: [
    { type: 'text', html: '<h3>小节标题</h3><p>正文段落……</p>' },
    { type: 'code', title: '例题 / 推导标题', code: '……', note: '可选：例题说明' },
    { type: 'tip', kind: 'tip', html: '<p>小贴士</p>' },   // kind: 'tip' | 'info' | 'warn'
    { type: 'table', title: '可选表格标题', headers: ['列1', '列2'], rows: [['a', 'b'], ['c', 'd']] },
    { type: 'list', ordered: true, items: ['条目1', '条目2'] },
  ],
  exercises: [
    {
      id: 'math-01-q1',                // 与章节 id 前缀一致
      type: 'choice',                  // 'choice' | 'multiple' | 'code' | 'fill'
      question: '题干……',
      code: '可选：题目给出的推导/过程',
      options: ['选项A', '选项B', '选项C', '选项D'],
      answer: 1,                        // choice/code：正确下标；multiple：正确下标数组 [0,2]
      accept: ['1/2'],                  // fill 类型必填：可接受答案数组（忽略大小写与首尾空格，尽量多写几种等价写法）
      explanation: '详细解析，讲清推导过程与各选项错因（40 字以上）。',
    },
  ],
};
```

## 数学公式书写规则（重要！）

App 不渲染 LaTeX，**公式必须用 Unicode 符号 + HTML 上下标书写**：

1. **允许的符号**：`√ ∑ ∫ π ∞ ≤ ≥ ≠ ≈ ± × ÷ → α β γ λ μ σ Δ ε δ ∂ φ θ π ⊂ ⊆ ∈ ∉ ·`
2. **幂与下标**：用 HTML 标签 `<sup>` 与 `<sub>`，如 `x<sup>2</sup>`、`a<sub>1</sub> + a<sub>2</sub>`、`e<sup>−x</sup>`、`2<sup>n</sup>`。
3. **变量**：斜体用 `<i>x</i>`；向量可用 `\vec` 的替代写法（直接写 `向量 a` 或加粗描述）。
4. **分式**：写成 `(分子)/(分母)`，如 `(a+b)/2`、`sin x / x`。
5. **极限**：写成 `lim(x→∞) f(x)` 或 `lim<sub>x→0</sub> sin x / x`。
6. **根号**：`√2`、`√(x<sup>2</sup>+1)`。
7. **矩阵**：用表格（type:'table'）或行内写法 `[a b; c d]`，并配文字说明。
8. **禁止**：`$...$`、`\frac`、`\sqrt`、`^{}`、`_{}` 等一切 LaTeX 语法；也不要使用 `<h1>/<h2>/<h4>`、`<img>`、`<table>`。

## 硬性规则

1. **章节结构**：每章 `sections` 含 **6~10 个小节**：至少 3 个 `text`、至少 2 个 `code`（例题/推导，用文字或伪代码展示解题过程）、至少 1 个 `tip`，可用 `table`（公式表、性质表、对比表）与 `list`（方法总结）补充。
2. **练习题**：每章 **6~8 道**，题型多样（单选/多选/推导题/填空），计算题**必须给出完整推导**；`answer` 下标必须真实正确；`explanation` 覆盖各选项错因。填空（fill）的 `accept` 尽量包含多种等价写法（如 '1/2'、'0.5'、'1/2 '）。
3. **`code` 块**：内容是"例题/解题推导"（计算步骤、伪代码、化简过程等文本），用模板字符串（反引号）包裹；内部出现反引号或 `${` 需转义；普通文本中若有 `\` 需写 `\\`。
4. **HTML 内容**：`text`/`tip` 的 `html` 用双引号字符串包裹。可用标签：`<h3>` `<p>` `<b>` `<strong>` `<i>` `<em>` `<code>` `<sup>` `<sub>` `<ul>/<li>` `<ol>/<li>` `<br>` `<span>`。
5. **中文内容**：全部简体中文，术语首次出现附英文（如：极限（limit）、行列式（determinant））。内容准确、严谨、循序渐进，面向工科本科生。
6. **不要**使用 require/import/export；只用模板里的写法。
7. 写完后用 `node --check` 检查语法，确保能被 Node 解析。

## 已分配的章节（只写你被分配的那些）

- 你的任务会明确列出要写的章节序号与标题清单。只创建清单中的文件，每章一个文件，内容不与其他章重复。

## 质量要求

- 内容像一本严谨的工科数学教材：定义/定理 → 直观理解 → 计算方法 → 例题 → 易错点/注意 → 小结。
- 例题步骤完整、数值正确；复杂计算给出关键中间步骤。
- 练习题有区分度：1~2 道送分题（概念），2~3 道中等题（套公式/基本计算），1~2 道易错题（常见陷阱，如极限存在条件、行列式性质误用、特征值重根等）。
- 每道题 `explanation` 覆盖所有选项错因，计算题把推导过程写清楚。
